YouTube Drive

Прототип для BMW iDrive · APTV

Введи точное название песни или видео. Плеер попробует найти первый результат и сразу открыть его, без списка для выбора.

Если сторонний поисковый сервер недоступен, кнопка откроет обычный поиск YouTube. Это тестовый вариант: автоматический запуск может быть ограничен браузером или YouTube.
Поиск первого результата использует публичный Invidious API без ключа. Доступность зависит от стороннего сервера. Никакие данные не сохраняются на этом сайте.
